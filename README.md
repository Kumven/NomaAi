## Feature Notes (remember & integrate)

**Product:** NomaAi is a personal AI agent for farming. It diagnoses crop problems
from photos, helps with technical and financial planning, and gives practical
guidance in the farmer's preferred language.

### Already designed (see SYSTEM_LOGIC_v4)
- AI chat for crop diagnosis (photos + text/voice), with credit-based limits
- Registration preferences: language + how the farmer wants replies (simple / normal / detailed)
- Free token allowance; subscription for unlimited use (Plus, Premium)
- Referrals to regional consultants and agro-dealers (insecticide, fertilizer, etc.)
- Free farmers' community + paid Premium group (WhatsApp)
- Weather advice (basic free, crop-specific uses a credit)
